门店开店清单

门店拿到账号后必做

📥 前置（总部/美团完成）

  • 主账号创建 + 门店绑定（连锁函审核）
  • 生成门店 ID / 账号密码表回传
  • 营业执照总部批量上传 + 商户通方案
  • 主账号确认商户通方案

🔧 门店自行操作（关键）

  • ① 登录：经营宝 APP，选「非餐饮商家」，优先账号密码
  • ② 改地址：店铺→门店信息，确保定位精准
  • ③ 改营业时间：避免非营业时段到店
  • ④ 设电话：400 虚拟号（PC 端申请）或自有号
  • ⑤ 绑银行卡：店铺全部服务→银行卡（必须先做）

📞 电话两种形式

  • 400 虚拟号：PC 端「店铺管理→电话模式」申请，呼入呼出均显示虚拟号（010/0310 开头）
  • 自有真实号：老板与用户互显真实号码

🚀 之后即可上品

  • 绑定银行卡后门店才能上产品
  • 总部统一上架最快；门店仅有上下架权限（下架待确认）
  • 选适用门店一键铺货

三种二维码

门店 / 品牌 / 直人
🏪

商家码

扫进去 = 单独这一家店。用于到店精准定位该门店下单。

🏷️

品牌码

扫进去 = 品牌离消费者最近的店。适合品牌统一投放。

💰

直人码

进最近的店，但绑定分佣账户：每成交一单，订单的 1% 进入该码绑定账户（用于阶梯超补打款）。

评价与门店权重

影响排名 · 影响销量

⭐ 消费者评价

  • 下单后可在门店页「去评价」打分
  • 大众点评可无消费打卡，亦积累权重
  • 评价影响门店搜索排名 → 影响团单销量

💬 门店回复

  • 好评：用 AI 智能回复 即可
  • 差评：人工针对订单解释、解决问题
  • 争取让用户撤销差评（护权重）

📊 星级计算

  • 根据用户评价动态计算星级
  • 星级 → 商户流 → 团单销量
  • 美团/抖音为本地逻辑，评价极重要

补贴政策体系

官方 / 货补 / 对补 / 超补

📐 官方新客户政策（黑骑士当前）

档位收返/补说明
不承诺上翻收 3 点货补 1 点相当于 2 点扣点（基础档）
承诺销量（可谈）收 0.4最高补到 2.6 点官方新客户上限政策
讲师私操作（待申请）收 3 点畅销品收三返三；其余收三返一/2.4部分品零扣点促动销

🔁 超补政策：收三返四（小牛案例）

目标 1.5 亿，额外补 4 个点（零成本核销再给 150 万）。其中 3 点货补、1 点可签框架/直人扫码返还。

阶梯打法：
• 前 5000 万：收 2 点
• 5000万–1亿：收 3 返 3
• 1亿–1.5亿：收 3 返 6
→ 整体核算 收 3 返 4

🤝 返还形式（三选路径）

  • 签框架：达目标后打款至品牌专用账户（限定死）
  • 直人扫码：绑定账户，每单 1% 进账，适合不自信规模的品牌
  • 阶梯：前段不补，超阈值后补（如上）
返到品牌指定账户需老板审核申请；讲师个人权限仅能操作「收三返三」类特定品。

🌿 待定的「准备期」诉求（黑骑士提）

黑骑士今年刚入驻、品未全上、又逢电动车淡季、双 11 将过，无法承诺销量。诉求：给 2–3 个月准备期，期内定一个收/返政策（如收多少返多少），量起来后再走平台标准政策。讲师表态：回去与「建中」沟通，未当场拍板。

关键问答

现场厘清的细节
Q门店能不能自己改库存 / 上品？▾

门店不能上品（总部统一上最快），但疑似可下架（待讲师确认）。总部不给管理权限则门店改不了库存等核心信息，需后续管控防乱套。

Q新增 / 删减门店怎么走？▾

仍走原流程：总部给表 → 美团讲师导入创建 → 生成门店 ID 回写表格 → 总部拿账号密码同步门店。门店自身无法新增。

Q门店营业执照能自己改吗？▾

可以自己修改；新增店铺则必须由总部提交。

Q上架要不要交保证金？▾

不用交保证金；只要是黑骑士加盟店（黑角部落）均可上架。

Q抖音门店信息能同步到美团吗？▾

首批门店信息已从抖音整批复制过来，需与门店重新核对。关店/信息变更时希望抖音侧能同步到美团主账号——机制待建立。

Q三个码是品牌统一还是各店独立？▾

后台有三类码：商家码（单店）、品牌码（最近店）、直人码（最近店+分佣），各自作用不同，非单一统一码。
